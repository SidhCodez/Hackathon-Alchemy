# Builder Alchemy

**Structured prompt systems for building products, careers, brands, and businesses.**

---

## 📌 What Is Builder Alchemy?

Builder Alchemy is a sister repository to [Hackathon Alchemy](https://github.com/SidhCodez/Hackathon-Alchemy.git). While Hackathon Alchemy helps teams win hackathons, **Builder Alchemy helps individuals build real things — products, careers, brands, and businesses — with structured, prompt-based guidance.**

Every category in this repository contains ready-to-use prompts that help you generate:
- Strategy documents
- Technical blueprints
- Execution plans
- Launch and delivery guides
- And much more

Whether you are launching an MVP, growing a YouTube channel, or starting a freelance business, Builder Alchemy gives you the blueprint.

---

## 🎯 Who Is This For?

- **Founders** launching MVPs and SaaS products
- **Freelancers** building a business and personal brand
- **Creators** launching YouTube channels, blogs, podcasts, and courses
- **Developers** building portfolios, APIs, and open-source projects
- **Students** preparing for jobs and self-learning roadmaps
- **Designers** building design systems and creative businesses
- **Anyone** who wants structure for building something meaningful

---

## 📂 Categories

Builder Alchemy has **10 Parent Groups** and **50 Categories**. See [CATEGORIES.md](CATEGORIES.md) for the full list.

---

## 🛠️ How to Use

1. Pick a category that matches what you're building.
2. Open that category's `PROMPT-BOOK.md`.
3. Follow the phases in order.
4. Copy each prompt into your AI tool (Claude, Cursor, ChatGPT, etc.).
5. Fill in the `[PASTE ...]` placeholders with your details.
6. Get structured outputs you can use immediately.

Each category follows the same 4-Phase system:
- **Phase 1:** Vision & Planning
- **Phase 2:** Blueprint & Design
- **Phase 3:** Execution & Quality
- **Phase 4:** Launch & Growth

# Contributing to Builder Alchemy

First off, thank you for considering contributing to **Builder Alchemy**! This repository exists to help builders, creators, and entrepreneurs structure their work with prompt-based systems.

## 📌 Project Overview

Builder Alchemy is a structured prompt library covering 50 categories across 10 parent groups. Every category contains a `PROMPT-BOOK.md` with prompts organized into 4 phases.

## 📂 Current Repository Structure

```text
Builder-Alchemy/
├── README.md
├── CATEGORIES.md
├── CONTRIBUTING.md
├── LICENSE
└── 01-Startup-and-Product/
    └── MVP-Building/
        └── PROMPT-BOOK.md
```

## 🛠️ How Can I Contribute?

### 1. Adding a New Category Prompt Book

1. Check the list of 50 categories in [`CATEGORIES.md`](CATEGORIES.md).
2. Create a new folder under the correct Parent Group (e.g., `02-Career-and-Personal-Branding/Job-Application-System/`).
3. Create a file named `PROMPT-BOOK.md`.
4. Follow the **4-Phase structure**:
   - Phase 1: Vision & Planning
   - Phase 2: Blueprint & Design
   - Phase 3: Execution & Quality
   - Phase 4: Launch & Growth

### 2. Improving Existing Prompt Books

1. Follow the **5-Part Blueprint** for every prompt:
   - Role
   - Input
   - Task
   - Sections
   - Constraints

### 3. Reporting Bugs or Typos

- Open an issue describing the problem.
- Submit a PR with the fix.

## 🚀 Pull Request Process

1. Fork the repository.
2. Clone your fork.
3. Create a branch: `git checkout -b feature/your-feature`
4. Commit: `git commit -m "Add: Prompt book for MVP Building"`
5. Push: `git push origin feature/your-feature`
6. Open a Pull Request against `main`.

## 📝 Style Guide

- Use **Markdown** for all documents.
- Keep language **beginner-friendly**.
- Use **tables** where comparisons help.
- Follow naming convention: `PROMPT-BOOK.md`

## 📋 Naming Conventions

| Type | Convention | Example |
| :--- | :--- | :--- |
| Parent Group Folder | `NN-Parent-Name` | `01-Startup-and-Product/` |
| Category Folder | `Category-Name` | `MVP-Building/` |
| Prompt Book File | `PROMPT-BOOK.md` | `PROMPT-BOOK.md` |
