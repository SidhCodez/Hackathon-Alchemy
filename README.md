Welcome to **Hackathon Alchemy** — a comprehensive repository of prompt packs designed to help you create any document for any hackathon category using AI. Whether you're building an AI/ML project, a no-code app, or a Web3 dApp, this repository provides structured prompts and context to generate professional documents quickly and accurately.

## Repository Structure

The repository is organized by **hackathon categories** (parent taxonomy). Each category contains **document packs** for various document types, following a 4-Phase workflow.

Each document pack includes:
- **Context template** – fill in your project details.
- **Prompt sequences** – step-by-step prompts for AI.
- **Examples** – sample outputs for reference.
- **Checklists** – ensure quality and completeness.

## Layer B — Tagging System

Use these tags to add context to any category or document pack:
- **Mode:** Online, Offline, Hybrid
- **Audience:** Students, Professionals, Beginners, Women-only, Corporate
- **Duration:** 24h, 36h, 48h, 1 week, Month-long
- **Outcome:** Prototype, MVP, POC, Startup, Research, Automation workflow
- **Difficulty:** Beginner, Intermediate, Advanced
- **Platform:** n8n, Make, Zapier, OpenAI, LangChain, AWS, etc.

## How to Use

1. Navigate to your hackathon category.
2. Choose the document type you need.
3. Open the prompt pack.
4. Fill in the context template with your project details.
5. Follow the prompt sequences with your AI assistant.
6. Refine using the provided checklists and examples.
